# Tasks

This folder holds implementation-ready tasks and the approved pickup list.

## Lifecycle

The lifecycle is not-started to in-progress to review to done. Parked requires
a concrete blocker; canceled records abandoned or superseded work. Completed
tasks move to done/ without renaming.

Every task has exactly one owning component. Task and component status must
match. Tracker identifiers are permanent and never reused.

## Flexible contract

Fold corrections and reasonable enhancements into an active task when they
strengthen the same outcome without materially changing product direction,
authority, security, provider commitment, public contract, dependency, effort,
or sequencing. Ask the repository owner before crossing one of those boundaries.

Independent task-grounded review is required before closure. Commit, push,
publication, release, cross-repository changes, and closure remain owner gates
unless the task records explicit standing authorization for the exact action.
