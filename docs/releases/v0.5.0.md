# Local Agent Runtime v0.5.0

Version `0.5.0` adds provider-neutral, bounded assistant-text events for
providers that can expose display-safe native output while they work. The first
implementation is the loopback LM Studio adapter.

## What changed

- Capable providers may emit ordered `assistant_text_delta` events containing a
  one-based provider-call `round` and non-empty display-safe `delta` text.
- LM Studio decodes its OpenAI-compatible SSE response, including arbitrarily
  fragmented UTF-8 and JSON frames, while keeping reasoning fields and tool-call
  fragments out of assistant-text events.
- Text fragments are coalesced into a bounded event budget that reserves room
  for the terminal event. Maximum-size output cannot swallow completion,
  failure, or cancellation.
- Provider-call rounds remain monotonic across initial work, application-tool
  continuations, and later user input in a reused session.
- `session_completed.text` remains the authoritative validated answer. A
  mismatch fails explicitly; canceled or failed sessions may retain provisional
  deltas but never gain a fabricated completion.
- Structured-output invocations and the Codex, Claude, Grok, and OpenRouter
  adapters remain on the complete-result path. The runtime does not manufacture
  streaming by splitting a completed response.
- The TypeScript host contract preserves the same normalized event and fields.

## Compatibility

The gateway API advances additively to `1.4.0`. Python and TypeScript packages
are released together as `0.5.0`; consumers must upgrade both pins.
