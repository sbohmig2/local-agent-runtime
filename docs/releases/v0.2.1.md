# Local Agent Runtime v0.2.1

Patch release for long-running authenticated loopback event streams.

## Change

The gateway now emits SSE comment heartbeats while an active event stream is
idle. Heartbeats create no runtime event, do not advance cursors or sequence
numbers, and are ignored by the TypeScript client. This prevents a healthy slow
provider turn from being cut off by a downstream five-minute idle body timeout.

## Compatibility

The gateway API remains `1.1.0`. Python and TypeScript packages are released
together as `0.2.1`; consumers must upgrade both pins.
