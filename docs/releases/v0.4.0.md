# Local Agent Runtime v0.4.0

Version `0.4.0` restores narrowly bounded provider-native public-web research
for the Codex, Claude, and Grok CLI routes and reports that capability through
the shared profile contract.

## What changed

- Reasoning profiles expose additive `capabilities.provider_native_web`
  metadata through Python, OpenAPI, and both TypeScript entry points.
- Codex receives live web search while shell, apps, browser/computer control,
  image generation, multi-agent work, project instructions, and raw network
  access remain disabled.
- Claude receives only `WebSearch` and `WebFetch`, with safe/restricted mode,
  empty setting sources, strict empty MCP configuration, no Chrome integration,
  and noninteractive permissions retained.
- Grok receives only `web_search` and `web_fetch`, with a private home,
  disposable sessions, no memory, subagents, or planning, and noninteractive
  permissions retained.
- Provider-native web work remains internal to the CLI turn and is never
  emitted as a consumer-owned application tool call.
- LM Studio and OpenRouter do not advertise this capability. Consumers may add
  separately authorized, bounded application tools through the existing tool
  contract.

## Compatibility

The gateway API advances additively to `1.3.0`. Python and TypeScript packages
are released together as `0.4.0`; consumers must upgrade both pins.
