# Local Agent Runtime v0.2.0

Provider-neutral model selection, reasoning controls, and managed adapter
inventory for independent consumers.

## Changes

- Add configured model selection and per-turn reasoning effort with exact
  requested/effective provenance and explicit unsupported combinations.
- Publish provider-owned capability, readiness, discovery, and task
  qualification metadata without treating any one of them as another.
- Add an unconditional catalog for Codex CLI, Claude Code CLI, Grok CLI,
  loopback LM Studio, and OpenRouter, with passive reads and bounded explicit
  installation probes.
- Add private managed activation for complete operator-approved profiles.
  Disabled, selected, task-routed, recently used, and configured-default states
  remain distinct and fail safely.
- Distinguish LM Studio's compatible model catalog from native loaded-instance
  state, preserving unknown when the two cannot be reconciled.
- Correct native CLI envelopes and keep trusted executable resolution,
  cancellation, output bounds, sandboxing, and secret redaction intact.

## Boundary

This release does not add a model marketplace, browser credentials, arbitrary
command or endpoint configuration, automatic fallback, billing, consumer UI,
consumer facts, product tools, or financial authority. Installed CLI presence
does not imply authentication, readiness, task qualification, local inference,
or permission to send data.

## Compatibility

The Python runtime, root TypeScript client, and `/host` entry point share
package version `0.2.0`. The additive gateway API is `1.1.0`. Consumers upgrade
the Python and TypeScript artifacts together from this release.

## Provider evidence and limits

Codex, Claude, Grok, and LM Studio completed synthetic tool-assisted turns.
Grok can still request its private `search_tool`, and Claude can intermittently
exit without output on a maximum-effort continuation; both fail closed and are
not claimed qualified for unattended product-tool execution. OpenRouter remains
setup-visible without model discovery or browser-owned credentials.
