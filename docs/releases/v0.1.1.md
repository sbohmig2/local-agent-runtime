# Local Agent Runtime v0.1.1

Initial public consumer release of the provider-neutral runtime contract.

## Distribution baseline

- Add the MIT License to the repository and both package manifests.
- Carry the exact MIT license text inside the Python wheel, Python source
  archive, and TypeScript client tarball; the release builder verifies this.
- Add a security policy and private vulnerability-reporting route.
- Make immutable GitHub Release URLs anonymously consumable after a complete
  repository-history audit.

Provider behavior, public runtime concepts, OpenAPI `1.0.0`, processing policy,
and consumer-owned tool authorization are unchanged. No provider was called and
no public package registry is used.

## Artifacts

- `local_agent_runtime-0.1.1-py3-none-any.whl`
- `local_agent_runtime-0.1.1.tar.gz`
- `local-agent-runtime-client-0.1.1.tgz`
- `SHA256SUMS`

The `v0.1.1` tag and first line of `SHA256SUMS` identify the exact reviewed
source commit. Consumers should download all four assets from the GitHub Release,
verify the manifest, and pin those immutable asset URLs in their own lockfiles.
Rollback restores the prior pinned release URLs and lockfiles; tags are never
moved and published assets are never replaced in place.

Maintainer build:

```bash
uv run python scripts/build_release.py
```

Consumer verification:

```bash
shasum -a 256 -c SHA256SUMS
```

See [Consumer integration](../integration.md) for installation and isolation.
