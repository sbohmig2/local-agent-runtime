# Local Agent Runtime v0.1.3

Reusable backend-only TypeScript host toolkit for independent consumers.

## Changes

- Add the optional `@local-agent-runtime/client/host` entry point alongside the
  unchanged root gateway client.
- Add provider-neutral process supervision with literal-loopback enforcement,
  exact runtime compatibility, secret exclusion, coalesced startup, bounded
  restart, sticky shutdown, and owned-child cleanup.
- Add an official MCP stdio catalog with explicit service identities,
  attributed server instructions, bounded discovery/results, cancellation, and
  duplicate or normalized-prefix collision rejection.
- Add bounded session coordination with consumer-injected trusted instructions,
  processing consent, two-layer tool authorization, continuation checks,
  ordered retained events, cumulative tool-round limits, maximum active
  duration, and safe cancellation recovery.
- Add an optional authenticated local HTTP/SSE adapter with exact Host and
  Origin validation, strong bearer authentication, bounded bodies and streams,
  validated cursors, immediate SSE connection, and non-hanging shutdown.
- Forward the separately modeled reasoning and embedding operations without
  owning consumer facts, retrieval, indexes, persistence, or workflow policy.

## Boundary

This release contains backend runtime infrastructure only. React components,
pages, HTML, browser-side model code, charts, chips, rendering semantics, and
product action meaning remain owned by each consuming application and are not
part of this package.

## Compatibility

The Python runtime, root TypeScript client, and `/host` entry point share
package version `0.1.3`. The gateway API remains `1.0.0`. Consumers upgrade the
Python and TypeScript artifacts together from this release.
