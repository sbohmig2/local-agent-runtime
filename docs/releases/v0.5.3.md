# Local Agent Runtime v0.5.3

Version `0.5.3` is a compatibility patch that scopes tool request identity to
the turn instead of the session (LAR-012).

## Changes

- Accept a tool request identifier that the provider reuses on a later turn of
  the same session once the earlier request's result was delivered. The
  OpenAI-compatible wire format scopes call identifiers to the assistant
  message that carries them, and the runtime's own JSON envelope for the CLI
  routes never required session-wide uniqueness; the runtime no longer enforces
  a stricter contract than the providers it fronts.
- Keep rejecting a duplicate identifier inside one provider response with the
  stable failure code `invalid_tool_request`.
- No wire, gateway, contract, configuration or client change.

The gateway API remains `1.4.0`. Python and TypeScript packages are released
together as `0.5.3` so consumers retain one matched runtime identity.
