# Local Agent Runtime v0.5.2

Version `0.5.2` is a compatibility patch that lets consumers distinguish an LM
Studio context-window overflow from an otherwise invalid provider response.

## Changes

- Recognize LM Studio's HTTP-200 SSE error frame and its non-streaming
  equivalent when bounded structured fields report
  `exceed_context_size_error` with a prompt larger than the active context.
- Publish the stable failure code `context_window_exceeded` with fixed safe text.
  Native provider messages and token counts remain outside public session state
  and events.
- Tolerate changes to the native human-readable wording and bounded diagnostic
  suffixes. A bounded message pattern is used only for compatible responses
  without structured fields.
- Preserve `invalid_provider_response` for malformed and unrelated provider
  errors.

The gateway API remains `1.4.0`; the existing failure-code field carries this
additive classification. Python and TypeScript packages are released together
as `0.5.2` so consumers retain one matched runtime identity.
