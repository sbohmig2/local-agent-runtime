# Local Agent Runtime v0.1.2

Typed-distribution correction for strict Python consumers.

## Change

- Include the standard empty `local_agent_runtime/py.typed` marker in the wheel
  and source distribution so type checkers use the package's inline type
  annotations.
- Make the release builder reject a Python wheel that omits or misstates the
  marker.

Provider behavior, runtime contracts, OpenAPI `1.0.0`, adapters, privacy
policy, and embedding behavior are unchanged. The matching TypeScript artifact
advances to `0.1.2` so consumers can continue pinning both packages from one
immutable release.
