# Operating philosophy

Build the smallest complete reusable capability that solves a present need in
at least two consuming projects. Prefer explicit contracts, observable limits,
and reversible choices over provider-specific convenience.

Agents may propose and orchestrate. Deterministic code validates configuration,
enforces processing policy, brokers tools, protects secrets, and records safe
provenance. A model response never creates product authority.

Keep implementation evidence honest. A configured adapter, healthy endpoint,
synthetic protocol pass, task qualification, consumer integration, and
production use are different claims.

Human direction remains decisive for new providers, external disclosure,
publishing, releases, cross-repository changes, and material scope expansion.
