# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting form in this repository's
**Security** tab. Do not disclose a suspected vulnerability, credential,
private prompt, provider response, or consumer data in a public issue.

Include the affected release, the smallest reproduction you can safely share,
the expected impact, and any known workaround. You should receive an initial
acknowledgement through the private advisory within seven days.

## Supported releases

Security fixes target the latest released patch version. Older releases may
receive a fix when the issue affects an immutable public contract and an
upgrade is not a practical mitigation.

## Scope

Reports about the runtime, authenticated loopback gateway, generated client,
provider adapters, release artifacts, or secret-redaction boundaries are in
scope. Provider services and consumer applications retain their own security
policies and should be reported to their respective owners.
